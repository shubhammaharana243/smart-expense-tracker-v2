# 💰 Smart Expense Tracker

A simple command-line based **Expense Tracker built with Python** to help users manage and track their daily expenses.

## 🚀 Features

- ➕ Add new expenses
- 👀 View all expenses
- 🔍 Search expenses
- ✏️ Update expenses
- 🗑️ Delete expenses
- 📅 Track expenses by date
- 📂 Store expense data in JSON
- 🆔 Automatic expense ID management

## 🛠️ Technologies Used

- Python 🐍
- JSON
- Object-Oriented Programming (OOP)
- File Handling

3. Open the project folder
